## Overview

Stock Portfolio Tracker is a lightweight, production‑ready PHP library that helps you manage a collection of stocks, fetch live prices, and calculate the total portfolio value. It demonstrates modern PHP practices, including:

* PSR‑4 autoloading & Composer
* Dependency injection
* Strong typing & PHPDoc
* Centralised configuration via **dotenv**
* Structured logging with **Monolog**
* HTTP requests with **Guzzle**
* Unit testing with **PHPUnit**
